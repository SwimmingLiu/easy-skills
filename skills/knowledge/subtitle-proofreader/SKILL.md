# 字幕校对专家

按 Pipeline 流程对字幕/口播文本做分批校对，确保所有条目都被处理且原文件不被修改。

## 输入与输出契约（硬规则）

### 结构与时长锁定（最高优先级）

校对只能修改字幕正文/口播文本，不得改变字幕结构。

- SRT/VTT 等带时间轴字幕：校对前后必须保持相同条目数、相同序号/标识符、相同开始时间、相同结束时间、相同单条时长、相同总时长
- 每条字幕的时间轴行必须原样保留，不能重排、平移、缩放、合并或拆分
- 字幕条目一一对应：第 N 条原字幕只能生成第 N 条校对字幕
- 普通逐字稿/录音稿：保持原有段落/条目数量，不增删、不合并、不拆分

任何会导致条目数、时间戳或时长变化的修改都必须放弃。

### 词库优先级

1. **用户内联词库**：对话中直接给出的术语（如"词库为：项目名、Skills、产品名"，逗号/换行/自由表述均可识别）
2. **内置词典**：`references/dictionary.md`

**合并规则**：两者合并使用，内联词库优先级更高。即使用户没提到内置词典，也自动加载作为补充。

### 输出规则

- ❌ **绝对不修改原始文件**
- ✅ 输出到原文件**同级目录**
- ✅ 文件名格式：`[原文件名]_已校对.[原扩展名]`
  - 例：`演示录音稿.srt` → `演示录音稿_已校对.srt`
- ✅ 同名已存在时追加数字：`_已校对2`、`_已校对3`

## 工作流程

### Step 1：分析与准备

1. 用 Read 读取完整文件，统计总行数与字幕条目数（SRT/VTT 以 cue/段落为准）
2. 如果是 SRT/VTT，建立结构基线：序号/标识符、每条开始时间、结束时间、单条时长、总时长
3. 读取 `references/dictionary.md`；如果用户给了内联词库，合并到内存词典中
4. 决定批次：
   - < 1000 行：1 批
   - 1000-3000 行：约每 1500 行 1 批
   - \> 3000 行：每 1000 行 1 批
   - 详细策略与边界对齐规则见 [references/proofreading-rules.md](references/proofreading-rules.md) 第三节

### Step 2：逐批次校对

对每个批次：

1. 用 Read 的 `offset` / `limit` 精确读取批次行
2. 把批次内容 + 合并后的词典 一并交给模型，按"必改/不改/需判断"规则校对
   - 详细规则见 [references/proofreading-rules.md](references/proofreading-rules.md) 第一节
   - 只允许改正文行；时间轴行、序号/标识符行、空行分隔结构必须原样保留
3. 记录本批次修改条目（编号 + 前后对比）
4. 把校对后的内容**直接累积到最终输出文件**（首批用 Write 创建，后续批次追加），不要建临时 batch 文件
5. 在进度表里标记本批次完成

### Step 3：完整性验证（强制门槛）

输出最终结果**之前**必须通过：

- 原文件条目数 == 校对后条目数
- SRT/VTT 的每条序号/标识符一致
- SRT/VTT 的每条开始时间、结束时间、单条时长一致
- SRT/VTT 的总时长一致
- 首条字幕完整存在
- 尾条字幕完整存在（含时间轴和文字）
- 随机抽查 5 个位置内容连续

如果是 SRT/VTT，必须运行：

```bash
python3 skills/subtitle-proofreader/scripts/verify_subtitle_integrity.py 原文件 校对后文件 --fix
```

脚本通过后才能交付；如果时间单位错位但条目结构仍可对齐，`--fix` 会自动用原文件时间轴修复校对后文件，并输出 `overlap_ratio` / `coverage_ratio` 等字幕交集指标。脚本仍失败时，按输出定位问题批次并修正，不得绕过。

任意一项不通过：停止输出 → 定位问题批次 → 补校 → 重新验证。

### Step 4：交付

验证通过后向用户输出：

- 校对后文件的绝对路径
- 修改统计与验证结果（模板见 [references/proofreading-rules.md](references/proofreading-rules.md) 第六节）

## Gotchas（最容易翻车的点）

- 写入了原文件 → 违反硬规则
- 用户内联词库被忽略，只用了内置词典
- 最后一批次内容丢失（行数不是 1000 整数倍时尤其常见）
- 没做完整性验证就交付
- 修改了时间戳或序号
- 校对后总时长或单条时长发生变化
- 批次边界切在字幕条目中间

完整 Gotchas 清单见 [references/proofreading-rules.md](references/proofreading-rules.md) 第二节。
