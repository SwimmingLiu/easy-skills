# QA 与导出

## 差异化检查

- 全局：页数、顺序、标题叙事链、主题一致性、用户要求覆盖率，以及 bundle JSON 与 manifest 是否一致。
- 数据页：指标口径、单位、时间范围、来源定位。
- 流程页：步骤顺序、分支、责任方和术语一致性。
- 图片页：`image-first` 检查整页图片存在、主体清楚、比例和裁切合理、exact text 可读、来源完整；`html-image-assisted` 检查视觉素材无文字、copy 与素材位置有足够对比度、HTML exact text 与草稿一致。
- 比较页：两侧维度一致，不制造虚假对称。
- 引用页：人物、原文和出处可核验。
- 结尾页：行动具体，不只写“谢谢”。

严重级别：`blocking` 阻止导出；`degraded` 表示某类检查或编辑能力不可用；`warning` 需要人工确认但不自动阻断。

## 浏览器 QA

推荐用 Playwright 在 1600×900 和窄屏视口检查：页面非空、元素不越界、没有文本遮挡、图片加载成功、缩略图和翻页可用、编辑后能保存。生成逐页截图或 contact sheet 供人工快速 Review。

## 输出能力

| 格式 | 能力 | 降级 |
|---|---|---|
| HTML | 两种模式均可播放与键盘交互；HTML 模式的文字来自结构化源 | 无 |
| 单文件 HTML bundle | JSON 与图片全部内嵌，可离线分发；HTML 模式保留视觉与 copy 的分离 | 不提供 raster 文字的独立编辑 |
| PDF | 高保真静态分发 | 无编辑能力 |
| PNG | 每个活动页一张图；HTML 模式先经浏览器截图 | 无编辑能力 |
| PPTX | 每页一张完整页面图片，保留讲者备注；HTML 模式先经浏览器截图 | 不提供独立文本/图形对象，写入 `export-report.json` |

PPTX 是整页图片封装，不声称文字可编辑。优先保证内容、层级和像素一致，再报告依赖或视觉降级。
