# 工作流

```mermaid
flowchart TD
  A[用户资料与目标] --> B[资料检查与缺口记录]
  B --> C[中心含义与五段叙事]
  C --> D[逐页主张、准确文字与视觉构思]
  D --> E{用户确认草稿}
  E -->|修改| C
  E -->|确认| F{选择模式}
  F -->|ai-image| G[选择图片主题并生成逐页提示词]
  G --> H[imagegen 生成完整页面图片]
  H --> I[图片页文字与构图检查]
  I -->|失败页| G
  F -->|html| J[选择 HTML 主题]
  J --> K[Bento 原生元素排版]
  K --> L[溢出、对比度与结构检查]
  L -->|失败页| K
  I --> M[写入 Bento 文档]
  L --> M
  M --> N[复开与逐页差异化 Review]
  N -->|通过| O[.bento.html 主文件与派生导出]
  N -->|未通过| D
```

## 草稿门禁

生成前先确定大致页数。每页只保留一个主张，并给出准确文字、证据状态和视觉构思。`ai-image` 在用户确认草稿之前不得调用生图；`html` 也不得绕过草稿直接排版。

## Review

逐页检查不是统一打勾。封面检查中心信息；数据页检查来源、单位与量级；流程页检查顺序和责任；对比页检查维度对齐；图片页检查主体、裁切、准确文字和多余文字；结尾页检查行动是否明确。任何阻断项未解决时，不得标记为完成。
