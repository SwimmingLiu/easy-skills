# 主题体系

八个主题按视觉语法去重，而不是按仓库或颜色命名：

| 主题 | 适用场景 | 核心特征 | 主要思想来源 |
|---|---|---|---|
| business-minimal | 汇报、管理层 | 安静、克制、证据优先 | editable-leadership-pptx、GordenPPTSkill |
| editorial | 叙事、报告 | 纸刊排版、强标题层级 | frontend-slides、beautiful-html-templates |
| swiss-grid | 品牌、设计 | 严格网格、高对比信号色 | frontend-slides、Dashi |
| launch-tech | 发布会、技术 | 青蓝、工程结构、少字 | wuming-cyan-circuit-launch-ppt |
| data-consulting | 战略、经营分析 | 图表优先、结论式标题 | GordenPPTSkill、editable-leadership-pptx |
| academic | 答辩、研究 | 引用、方法、证据链 | academic-pptx-skill |
| brand-bold | 创意、产品 | 强品牌色、海报式构图 | Dashi、beautiful-html-templates |
| premium-dark | Keynote、高端发布 | 深色、高反差、克制装饰 | codex-ppt-skill、wuming-cyan-circuit-launch-ppt |

整页生图的简洁性参考 wuming-cyan-circuit-launch-ppt 与 codex-ppt-skill；HTML 播放、键盘导航和动效思路参考 ppt-master、frontend-slides 与 html-ppt-skill；结构化内容与导出边界参考 anthropics/skills pptx、MiniMax pptx-generator、presentation-skill 和 Bento。未复制其代码或模板。

选择主题时先看用途、受众、内容类型和素材质量，再给 3 个候选。变体只改变有限色彩和语气，不应复制成新的主题家族。
